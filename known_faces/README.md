# Known Faces Database

Add photos of people you want VASIS to recognize.

## How to Add Faces

1. Take a clear photo of the person's face (front-facing, good lighting)
2. Save it to this folder
3. **Name the file with the person's name** (this becomes the display name)

## Naming Examples

| Filename | Display Name |
|----------|--------------|
| `mom.jpg` | Mom |
| `brother.jpg` | Brother |
| `John_Smith.jpg` | John Smith |
| `best_friend.png` | Best Friend |

## Tips for Best Results

- Use well-lit, front-facing photos
- One face per image
- Avoid blurry or low-resolution images
- Supported formats: `.jpg`, `.jpeg`, `.png`

## Privacy Note

All face recognition happens **locally on your laptop**. 
Images are never sent to the cloud.
